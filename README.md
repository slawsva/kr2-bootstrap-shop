# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

ShopProject — самостоятельная реализация учебного интернет-магазина техники для учёбы на Bootstrap 5.3.8. Это отдельный проект, а не подключение фреймворка поверх CSS контрольной №1.

## Запуск

Открыть `index.html` в браузере. Сборка, npm и интернет не требуются: Bootstrap и изображения включены в проект. Для HTTP-просмотра можно запустить `python3 -m http.server 8000` из папки проекта и открыть `http://localhost:8000`.

## Структура

- `index.html` — главная: навигация, hero-блок, преимущества и карточки.
- `catalog.html` — каталог на сетке Bootstrap и выбор категории.
- `product.html` — подробная карточка StudyBook 14, схема клавиатуры и вкладки.
- `product-notetab.html`, `product-focussound.html`, `product-codekeys.html` — подробные страницы остальных товаров.
- `order.html` — доступная форма заявки и подтверждение через модальное окно.
- `css/custom.css` — собственное оформление поверх компонентов Bootstrap.
- `js/catalog-data.js` — названия и учебные цены товаров для формы.
- `js/main.js` — валидация, сводка ошибок, двухэтапная заявка, фильтр каталога и переключение изображения.
- `images/` — схематические SVG-иллюстрации.
- `vendor/bootstrap/` — официальные Bootstrap CSS, JS bundle и MIT-лицензия.

## Четыре самостоятельные доработки из пункта 14 практической №8

1. **Собственное оформление проекта.** Простой интерфейс в стиле КР1: белый фон, синие кнопки, светло-голубой первый экран и одинаковые карточки. Для КР2 заново сделана разметка на Bootstrap и добавлены свои стили карточек, вкладок и формы. CSS КР1 не подключается. Сохранены привычные названия и содержание.
2. **Более подробная карточка товара.** На всех страницах товаров есть вкладки «Для каких задач», «Характеристики» и «Комплектация», а также ограничения выбора. У ноутбука два представления: общий вид и схема клавиатуры. Все данные демонстрационные.
3. **Улучшенное модальное окно.** Быстрая заявка открывается с выбранным товаром. После проверки полей показывается отдельный этап с данными для подтверждения. Можно вернуться к редактированию без потери ввода. Успех показывается только после подтверждения. Форма на странице заявки использует то же окно проверки.
4. **Улучшенная доступность формы.** У полей есть подписи, текстовые ошибки и связь через `aria-describedby`; ошибки отмечаются `aria-invalid`. Над формой появляется сводка со ссылками на неверные поля, фокус переводится на первое ошибочное поле. Исправления обновляют ошибки; сброс их очищает. Модальное окно удерживает фокус, закрывается Escape и возвращает фокус к исходному элементу. Есть ссылка пропуска навигации и видимый клавиатурный фокус.

Список выбранных доработок требует согласования с преподавателем; проект не является подтверждением такого согласования.

## Как показать преподавателю

1. На главной показать простое оформление, сетку Bootstrap, карточки и адаптивное меню.
2. В каталоге выбрать категорию, открыть товар и переключить все три вкладки. У ноутбука переключить виды изображения.
3. Нажать «Заявка», проверить выбранный товар. Отправить пустую форму: показать текстовые ошибки, сводку и фокус первого поля.
4. Заполнить имя, e-mail, телефон и согласие. Открыть подтверждение, нажать «Исправить данные», убедиться в сохранении ввода.
5. Подтвердить заявку и показать учебное сообщение об успехе. Повторить сценарий на `order.html?product=codekeys`.
6. Сузить окно до мобильной ширины, раскрыть меню, проверить вкладки и модальное окно с клавиатуры.

## Проверка

Проверено в Chrome: все семь страниц, локальные ссылки и изображения, сетка Bootstrap, категории каталога, вкладки и виды товара, валидация e-mail и телефона, сводка ошибок, цикл подтверждения и редактирования, сброс, Escape и удержание фокуса. На ширинах 390px и 768px переполнения страницы нет. Ошибок JavaScript и HTTP не обнаружено; формы не выполняют сетевую отправку данных.

## Ограничения

Проект статический, без бэкенда, оплаты и настоящих продаж. Данные заявки не сохраняются в localStorage и не отправляются на сервер. Оформление формы не означает полную сертификацию соответствия WCAG. Названия, цены, характеристики, комплектация и изображения учебные.
